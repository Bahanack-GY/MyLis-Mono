# Product

## Register

product

## Users

SMB managers, department heads, accountants, commercial teams, and employees at small-to-mid-size businesses in Francophone Africa (Senegal, Ivory Coast, and neighboring markets). Each user type carries a distinct role (CEO, Manager, Head of Department, Accountant, Commercial, Employee, Intern) with scoped access and a purpose-built dashboard.

Context of use: a working day. Users open MyLiS to get something done — approve a leave request, check an invoice, review a lead, submit a task update. The interface competes with WhatsApp and spreadsheets for attention. It must win on speed, clarity, and trust.

The product is French-first. Most users read French as their primary business language, with English available for international configurations.

## Product Purpose

MyLiS is an all-in-one ERP and CRM for growing Francophone African businesses. It centralizes HR (attendance, leave, payroll, discipline), accounting (invoices, expenses, financial reports, cash flow), commercial operations (leads, clients, pipeline, opportunities), and project management under one role-aware platform.

Success looks like this: a business stops using Excel for headcount tracking, stops texting the accountant for expense approvals, and stops losing leads in email threads. MyLiS becomes the operating layer the whole team uses to run the business.

## Brand Personality

Professional, precise, trustworthy. The product earns credibility by being exact: correct numbers, predictable layouts, consistent behavior. It does not try to delight through decoration. It delights through reliability.

Three words: **Precise. Reliable. Composed.**

## Anti-references

- **Generic SaaS minimalism** (Notion, Linear, Loom aesthetic): rounded corners everywhere, soft grays, generous whitespace, pastel icon sets. This read as startup-for-startups, not a professional operations tool used by an accountant in Abidjan.
- **Legacy enterprise software** (SAP, Oracle, old Microsoft Dynamics): dense gray toolbars, table-overload, Windows XP chrome. MyLiS should feel modern without being trendy.
- **Consumer/social apps**: vibrant, playful, attention-seeking. The UI is not competing for dopamine — it is competing for trust.

## Design Principles

1. **Clarity earns credibility.** Every screen should answer a question without asking another. Labels, headings, and data must be unambiguous. Decoration that does not carry information is noise.
2. **Role-appropriate density.** An accountant and an intern see very different things. Complexity is earned by role, not dumped on everyone. Dense views are fine when the user is equipped for them.
3. **The interface is an instrument, not a canvas.** Hard edges, precise spacing, and consistent color application communicate that data is reliable. Visual ornamentation undermines that signal.
4. **Operational pace.** Menus, flows, and layouts serve a working rhythm: fast to scan, fast to act. Nothing should require three clicks when one will do.
5. **Locally grounded.** Language, tone, and workflow assumptions should fit Francophone African business culture — not Silicon Valley defaults dressed in French.

## Accessibility & Inclusion

WCAG 2.1 AA. Keyboard navigation, sufficient color contrast, screen-reader-compatible markup, and reduced-motion support are non-negotiable baselines. Input focus states and modal focus traps are already implemented — maintain and extend this pattern.
